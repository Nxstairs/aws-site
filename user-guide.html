アカウント登録開始

AWS LENDING公式サイトの 「今すぐ始める」をクリック／タップしてください。

SCREEN IMAGE

新規会員登録画面

Step.2

新規会員登録

本人確認に必要な書類をご用意のうえ、 新規会員登録へ進んでください。

SCREEN IMAGE

メールアドレス登録画面

Step.3

メールアドレス登録

登録するメールアドレスを入力します。

ご利用規約・リスク説明・ プライバシーポリシーをご確認のうえ、 登録手続きを進めてください。

SCREEN IMAGE

電話番号登録画面

Step.4

電話番号登録

ご利用になる電話番号を入力し、 認証手続きへ進みます。

SCREEN IMAGE

SMS認証画面

Step.5

SMS認証

登録した電話番号へ届いた 認証コードを入力してください。

SCREEN IMAGE

会員情報入力画面

Step.6

会員情報を登録

氏名・生年月日・住所など、 必要な基本情報を入力してください。

続いて本人確認に必要な 手続きを行います。

SCREEN IMAGE

登録完了画面

Step.7

会員登録完了

登録内容と本人確認が完了すると、 AWS LENDINGをご利用いただけます。

2

レンディング

01

暗号資産を入庫

まず、貸し出したい暗号資産を AWS LENDINGの貸出準備ウォレットへ送信します。

SCREEN IMAGE

マイページ

Step.1

貸出準備ウォレットへ進む

マイページから 「暗号資産を入庫する」を選択します。

SCREEN IMAGE

暗号資産選択

Step.2

暗号資産を選択

入庫する暗号資産を選択します。

BTC ETH USDT USDC
SCREEN IMAGE

入庫アドレス

Step.3

暗号資産を送信

画面に表示された入庫先アドレスを確認し、 ご利用の取引所またはウォレットから 暗号資産を送信します。

注意

暗号資産を送信する際は、 通貨・ネットワーク・送信先アドレスを 必ず確認してください。

SCREEN IMAGE

入庫完了

Step.4

入庫完了

必要なネットワーク承認が完了すると、 マイページに暗号資産が反映されます。

入庫しただけでは、 レンディングは開始されません。

02

貸出申請

入庫した暗号資産を使って、 レンディングの貸出申請を行います。

SCREEN IMAGE

貸出申請画面

Step.1

貸出申請へ進む

貸出準備ウォレットから 「貸出する」を選択します。

SCREEN IMAGE

プラン選択

Step.2

プランを選択

STANDARD 年利 10%
PREMIUM 年利 14%
SCREEN IMAGE

貸出数量入力

Step.3

貸出数量を入力

貸し出す暗号資産の数量を入力し、 契約内容をご確認ください。

SCREEN IMAGE

貸出完了

Step.4

レンディング開始

申請が完了すると、 契約条件に基づいてレンディングが開始されます。

3

運用状況の確認

SCREEN IMAGE

AWS LENDING マイページ

MY PAGE

資産状況を確認

マイページでは、 貸出中の暗号資産や契約プラン、 利息などの運用状況を確認できます。

  • 貸出中の暗号資産
  • 貸出数量
  • 契約プラン
  • 契約期間
  • 利息
4

返還・出庫

SCREEN IMAGE

契約状況

Step.1

契約状況を確認

マイページから、 対象となるレンディング契約を確認します。

SCREEN IMAGE

返還画面

Step.2

資産の返還

契約条件に基づき、 契約期間終了後に暗号資産と利息が 貸出準備ウォレットへ反映されます。

SCREEN IMAGE

出庫申請

Step.3

出庫申請

出庫する暗号資産と数量、 送信先アドレスを入力してください。

SCREEN IMAGE

出庫完了

Step.4

出庫完了

手続き完了後、 指定したウォレットへ暗号資産が送信されます。
