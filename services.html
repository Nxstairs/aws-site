ABOUT

AWS LENDINGとは

暗号資産を貸し出し、
利息を受け取る。

AWS LENDINGは、 お客様から暗号資産を借り受け、 その資産を各種事業に活用することで 収益の獲得を目指すレンディングサービスです。

お客様には、ご利用いただくプランの 契約条件に基づいて利息をお支払いし、 契約期間終了後に暗号資産を返還します。

FLOW

AWS LENDINGの流れ

01

資産を送る

対象となる暗号資産を 当社の指定されたウォレットへ送信します。

02

貸し出す

プランを選択し、 暗号資産の貸し出しを開始します。

03

利息を受け取る

契約条件に基づき、 貸し出した資産に対する利息（年利10～14％）が計算されます。

04

資産が戻る

契約期間終了後、 条件に基づいて元本と利息をお客様指定のウォレットへ返還します。

AWS LENDINGが選ばれる

3つの理由

01. 増える

GROW

「最大14%」
国内最高水準の利率

AWS LENDINGでは、 お客様から借り受けた暗号資産を 各種事業に活用し、 事業活動から収益の獲得を目指します。

その仕組みを通じて、 契約条件に基づいた利息を お客様へお支払いします。

利率10〜14%を実現できる理由は、
暗号資産運用×実業への出資の「ハイブリッド出資」

AWS LENDINGは、お客様からお借りした暗号資産を 暗号資産市場で運用するだけではありません。
「暗号資産運用」と「実業への出資」を組み合わせた 独自の仕組み（ハイブリッド出資）により、市場の波に左右されにくい 安定した収益基盤を構築しています。

暗号資産運用

10社以上の国内外の暗号資産ファンドへ分散投資を行い、 安全かつ効率的に収益を確保します。

×

実業への出資

一部の暗号資産を円転して確度の高い事業に出資し、 収益基盤を構築しています。

02. 守る

PROTECT

お客様の暗号資産を守るための
安全性と透明性

お客様から借り受ける暗号資産を 適切に取り扱うため、 AWSでは資産管理や情報管理などの 運用体制の整備に取り組みます。

1. 資産管理体制の整備
2. 複数担当者による確認
3. 情報管理体制の強化

1. 資産管理体制の整備

Aお客様からお借りした大切な暗号資産は、 インターネットから完全に切り離された 「専用の保管庫（コールドウォレット）」で自社管理しています。
ハッカーの手が届かない場所に置くことで、 盗難のリスクをなくします。

2. 複数担当者による確認

AWS LENDINGでは、お客様からお借りした暗号資産をより厳格に管理するため、 必ず複数担当者によって確認します。
暗号資産を動かす時は、複数の担当者が役割を分けて厳しくチェックすることによって、 内部の不正やミスの発生を防ぎます。

3. 情報管理体制の強化

AWS LENDINGは、お客様情報を適切に管理するため、 情報管理体制の整備・強化をしています。
個人情報やお借りした暗号資産に関する情報へのアクセスを適切に管理し、 情報漏えいや不正利用の防止に努めています。

03. 戻る

RETURN

契約期間終了後に
資産を全て返還

レンディング期間終了後、 契約条件に基づいて お客様の暗号資産を返還します。

返還時は、お客様ご指定のウォレットへ 貸し出した暗号資産に利息を加えた全ての資産を返還します。

1. 最短1か月後から返還可能
2. 迅速な返還対応

1. 最短1か月後から返還可能

暗号資産が長期間ロックされる不安を解消します。
スタンダードプランを選択されたお客様は1か月後から、 プレミアムプランを選択されたお客様は12か月後から全ての資産を返還可能です。

2. 迅速な変換対応

お客様の返還申請後、最短2営業日で全ての資産を返還します。
返還申請は、当社ホームページよりいつでも行えます。

RISKS & SECURITY

様々なリスク

AWS LENDINGでは、以下のリスクを考慮しています。

01

市場リスク

暗号資産の価格変動リスク 暗号資産の市場価格は大きく変動する可能性があり、 貸出期間中に資産価値が変化する場合があります。

02

信用リスク

貸出先の経営破綻リスク お客様からお借りした資産を貸し出している相手(運用先)が、 経営破綻などによって資産を返せなくなってしまうリスクがあります。

03

流動性リスク

資産がすぐに引き出せないリスク レンディングの性質上、銀行預金のように「今すぐ」お手元に戻すことができない期間が生じます。

04

運営リスク

ハッキング・内部不正・システム障害リスク 運営会社の管理不足による盗難やシステムトラブルのリスクです。

05

規制リスク

法律の変化 暗号資産を取り巻く法制度が変わり、サービスに影響が出るリスクです。
