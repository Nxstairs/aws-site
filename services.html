ABOUT

暗号資産レンディングサービス
AWS LENDINGとは

暗号資産を貸し出し、
利息を受け取る。

AWS LENDINGは、 お客様から暗号資産を借り受け、 その資産を各種事業に活用することで 収益の獲得を目指すレンディングサービスです。

お客様には、ご利用いただくプランの 契約条件に基づいて利息をお支払いし、 契約期間終了後に暗号資産を返還します。

FLOW

AWS LENDINGの流れ

01

資産を送る

対象となる暗号資産を 当社の指定されたウォレットへ送信します。

02

貸し出す

プランを選択し、 暗号資産の貸し出しを開始します。

03

利息を受け取る

契約条件に基づき、 貸し出した資産に対する利息（年利10～14％）が計算されます。

04

資産が戻る

契約期間終了後、 条件に基づいて元本と利息をお客様指定のウォレットへ返還します。

AWS LENDINGが選ばれる

3つの理由

01. 増える

GROW

暗号資産を貸し出して、
新たな価値へ。

AWS LENDINGでは、 お客様から借り受けた暗号資産を 各種事業に活用し、 事業活動から収益の獲得を目指します。

その仕組みを通じて、 契約条件に基づいた利息を お客様へお支払いします。

02. 守る

PROTECT

大切な資産を扱うための、
管理体制。

お客様から借り受ける暗号資産を 適切に取り扱うため、 AWSでは資産管理や情報管理などの 運用体制の整備に取り組みます。

01 資産管理体制の整備
02 複数担当者による確認
03 情報管理体制の強化
03. 戻る

RETURN

契約期間終了後、
資産を返還。

レンディング期間終了後、 契約条件に基づいて お客様の暗号資産を返還します。

返還条件や手続きについては、 ご利用前に契約内容をご確認ください。

RISKS & SECURITY

様々なリスク

暗号資産レンディングには 以下のようなリスクがあります。

01

市場リスク

暗号資産の市場価格は大きく変動する可能性があり、 貸出期間中に資産価値が変化する場合があります。

02

信用リスク

事業や取引先などの状況により、 元本や利息の返還に影響が生じる可能性があります。

03

流動性リスク

契約期間中は、 暗号資産を自由に移動・売却できない場合があります。

04

システムリスク

システム障害、通信障害、 サイバー攻撃などによって サービスに影響が生じる可能性があります。

05

法令・規制リスク

暗号資産に関する法令や制度の変更により、 サービス内容が変更される可能性があります。
